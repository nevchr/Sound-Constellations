Sound Constellations turns your local sample library into an interactive acoustic map. Explore nearby sounds, preview them instantly, and discover connections beyond folder names — entirely on your computer.

### Download

- **Sound-Constellations-Setup-0.1.0-x64.exe** — recommended. A guided Windows installer with Start menu and desktop shortcuts, plus a standard uninstaller.
- **Sound-Constellations-Portable-0.1.0-x64.exe** — the same app in one executable, without installation or shortcuts.
- **SHA256SUMS.txt** — checksums for both downloads.

Choose either edition. Node.js, Python, FFmpeg, and other development tools are **not required**. The runtime and decoder are bundled; after downloading, installation and use are offline.

### Included

- Interactive 3D and 2D constellations based on measured audio features.
- WAV, MP3, FLAC, OGG and M4A scanning, with graceful handling of damaged files.
- Click-to-preview playback, waveform display, looping, volume and keyboard controls.
- Search, folder/format/duration filters, and nearest-sound connections.
- Local SQLite cache, incremental rescans, cancellation and saved settings.
- Read-only access to your source library. No accounts, uploads, telemetry or cloud services.

### Compatibility and notes

Windows 10/11 on Intel or AMD x64, with a working graphics driver. This is an unsigned early release, so Windows may show an unknown-publisher or SmartScreen warning. Previews cover the first 30 seconds of each file. The portable edition also keeps settings and cache in the Windows user profile.

The repository and downloads are public. No GitHub account is needed to download, install, or use the app.

See [installation instructions](https://github.com/nevchr/Sound-Constellations/blob/main/docs/INSTALL.md) and [verification notes](https://github.com/nevchr/Sound-Constellations/blob/main/VERIFICATION.md) for details.
